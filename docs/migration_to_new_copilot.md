# Migration checklist

Follow `README.md` for this branch's three local configuration files and inventory
setup. See `SYSTEM_HANDOVER.zh-CN.md` for account, asset and acceptance forms.

Transfer code separately from controlled runtime data. Obtain independent
GitHub, Copilot, HSD, SSH and mail permissions for the successor. Restore any
approved database/report backup consistently and start with loopback UI access.

Use staged acceptance: offline UI tests, Stage 1 plan only, approved HSD read,
SSH identity check, then an explicitly authorized hardware window. Do not use
historical sample addresses, images or known-good logs as deployment defaults.

The distributed machine inventory example is intentionally non-operational.
Optional internal extended skills and collateral are obtained separately through
approved internal channels.
